# CarePath

Patient-care and appointment-management frontend for clinics and hospitals.

Book visits, skip waiting rooms, and track live queue tokens from one place.

## Scripts

```bash
# Install dependencies
npm install

# Start the development server
npm run dev

# Production build
npm run build
```

## Routes

- `/` Home
- `/login` Login and registration
- `/doctors` Doctor directory
- `/dashboard` Patient dashboard
- `/book-appointment` 3-step booking
- `/appointments` Appointment history
- `/queue` Live token tracker
- `/medical-records` Records
- `/profile` Patient profile
- `/notifications` Alerts
